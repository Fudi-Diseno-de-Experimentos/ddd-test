# ddd-test

Proyecto base con Spring Boot y enfoque DDD para experimentar una arquitectura por capas.

La aplicacion usa una base de datos MySQL y toma variables de entorno desde un archivo `.env` en la raiz del proyecto.
La base de datos se crea automaticamente si no existe cuando la aplicacion inicia.
La documentacion de la API esta disponible en Swagger.

URL de Swagger:
http://localhost:8080/swagger-ui.html
